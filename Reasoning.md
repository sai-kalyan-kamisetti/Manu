## 1. Analogies

**A. Important Formulas and Concepts**

| Type | Typical relationship |
|---|---|
| Word | Object : function, part : whole, tool : user, cause : effect, degree, symbol : meaning, place : person |
| Letter | Same shift on each letter (+2), reverse shift, alternate shifts, position values (A = 1 … Z = 26) |
| Opposite letter | Position + opposite position = 27 (A↔Z, C↔X, J↔Q) |
| Number | n² ± 1, n³ ± 1, ×k + c, sum or product of digits |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Make a sentence | "A is used to B" → apply the same sentence to the second pair | All word analogies | Pick the narrowest true sentence; "Pen : Write" is better than "Pen : Hold" |
| Check both sides | Same relationship in both pairs, same order | Word and number analogies | Don't reverse the order of the pair |
| Positions for letters | Write numbers under letters, find the shift | Letter analogies | Slow if you don't know EJOTY (5, 10, 15, 20, 25) |
| 27-sum rule | Opposite letter = 27 − position | Mirror-alphabet codes | Only for A–Z opposites |
| Test options on the first term | See which option gives the first pair's relationship | Number analogies | Check the second term too |

**C. Three Mandatory Solved Examples**

**Easy**
Pen : Write :: Knife : ? (a) Cut (b) Sharp (c) Handle (d) Steel.
1. Pen is used to write → knife is used to cut.
2. Answer: **(a) Cut**.
- Fastest method: sentence method. Time: **10 s**.
- Common mistake: choosing "Sharp" (a property, not a function).

**Medium**
CAT : ECV :: DOG : ? (a) FQI (b) EPH (c) FPI (d) GRJ.
1. C → E, A → C, T → V: each letter +2.
2. D → F, O → Q, G → I → **FQI**. Answer: **(a)**.
- Fastest method: check the first letter's shift, then confirm on the last letter. Time: **25 s**.
- Common mistake: shifting only the first letter and picking a near-match option.

**Tough**
4 : 65 :: 6 : ? (a) 37 (b) 121 (c) 215 (d) 217.
1. Test n³ + 1 on the first pair: 4³ + 1 = 65 ✓.
2. 6³ + 1 = 216 + 1 = **217**. Answer: **(d)**.
- Fastest method: try n² ± 1 first, then n³ ± 1 (65 is too big for 4²). Time: **35 s**.
- Common mistake: using n² + 1 (gives 37 for 6) because it fits small numbers.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) Doctor : Hospital :: Teacher : ? (a) School (b) Book (c) Student (d) Chalk. **Answer (a).** Worker : workplace.
2. (Easy) Seed : Plant :: Egg : ? (a) Nest (b) Shell (c) Chick (d) Farm. **Answer (c).** What it grows into.
3. (Medium) FAME is to GBNF as BOLT is to ? (a) CPMU (b) CPNU (c) APKS (d) CPMV. **Answer (a).** Each letter +1: B→C, O→P, L→M, T→U.
4. (Medium) 8 : 65 :: 11 : ? (a) 120 (b) 121 (c) 122 (d) 132. **Answer (c).** 8² + 1 = 65; 11² + 1 = 122.
5. (Tough) JK : QP :: ST : ? (a) GH (b) HG (c) HF (d) IG. **Answer (b).** J(10) + Q(17) = 27 and K(11) + P(16) = 27 → opposite letters; S(19) ↔ H(8), T(20) ↔ G(7) → HG.

**E. Exam-Oriented Application**
Analogies reward vocabulary and fast relation-spotting. I could not verify whether AAI JE (Operations) asks them. This is general advice: practise word, letter and number types equally. Priority: the sentence method and letter-position fluency.

**F. Quick Revision**
- Rules: same relation, same order; opposite letter sum = 27.
- Time-savers: sentence method; EJOTY; try n² ± 1 then n³ ± 1.
- Reminders: check both terms of the second pair.
- Mistakes: picking a property instead of a function; reversing the pair order.

## 2. Classification

**A. Important Formulas and Concepts**

| Type | What to check |
|---|---|
| Word | Category, function, living / non-living, origin |
| Letter-cluster | Gap inside each cluster, gap between clusters, vowels, reverse order |
| Number | Prime, square, cube, parity, divisibility, digit sum, pattern (n² ± 1) |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Majority property | Find the property shared by 3 of 4 | All types | If two properties both split the group, try the next property |
| Number checklist | Parity → prime → square/cube → divisibility → digit sum | Number groups | Stop at the first property that isolates one item |
| Letter gaps | Convert to positions, compare internal gaps | Letter clusters | Also compare gaps between clusters |
| Odd position in an AP | Common difference breaks at one item | Sequences in groups | Needs ordered items |

**C. Three Mandatory Solved Examples**

**Easy**
Choose the odd one: (a) Apple (b) Mango (c) Potato (d) Banana.
1. Apple, mango and banana are fruits; potato is a vegetable.
2. Answer: **(c) Potato**.
- Fastest method: category check. Time: **8 s**.
- Common mistake: overthinking botanical edge cases (tomato-type items). Use the everyday category.

**Medium**
Choose the odd one: (a) 41 (b) 43 (c) 47 (d) 51.
1. 41, 43 and 47 are prime. 51 = 3 × 17.
2. Answer: **(d) 51**.
- Fastest method: prime check on each option. Time: **20 s**.
- Common mistake: assuming 51 is prime. Check the digit sum: 5 + 1 = 6, divisible by 3.

**Tough**
Choose the odd cluster: (a) GJ (b) KN (c) OR (d) SU.
1. G(7)–J(10): gap 3. K(11)–N(14): gap 3. O(15)–R(18): gap 3. S(19)–U(21): gap 2.
2. Answer: **(d) SU**.
- Fastest method: write positions, compare gaps. Time: **30 s**.
- Common mistake: comparing the gap between clusters (+4 each) and finding no difference, then guessing.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) Lion, Tiger, Leopard, Cow. **Answer: Cow.** The others are wild big cats.
2. (Easy) Square, Triangle, Circle, Cube. **Answer: Cube.** The others are 2-D shapes.
3. (Medium) 121, 144, 169, 200. **Answer: 200.** The others are perfect squares.
4. (Medium) 14, 21, 35, 40, 56. **Answer: 40.** The others are multiples of 7.
5. (Tough) 26, 37, 50, 64. **Answer: 64.** 26 = 5² + 1, 37 = 6² + 1, 50 = 7² + 1; 64 is not of the form n² + 1 (the series would give 65).

**E. Exam-Oriented Application**
Classification is quick to attempt and is a safe "scoring" topic in general government exams. I could not verify AAI-specific frequency. Priority: number checklist and letter-gap method.

**F. Quick Revision**
- Rules: find the property that 3 of 4 share.
- Time-savers: number checklist; positions for letters.
- Reminders: use the everyday category for word questions.
- Mistakes: stopping at the first property that fits; mis-classifying composites as primes.

## 3. Series

**A. Important Formulas and Concepts**

| Pattern | Look for |
|---|---|
| Arithmetic | Constant difference |
| Second order | Differences themselves in AP or GP |
| Geometric / mixed | ×k, ×k + c, ×k − c |
| Squares / cubes | n², n³, n² ± 1, n³ ± n |
| Alternating | Two interleaved series (odd and even positions) |
| Prime | 2, 3, 5, 7, 11, 13, 17 … |
| Letter | Position shifts; also mirrored pairs (AZ, BY, CX) |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Difference ladder | Write differences; if not constant, write differences of differences | Slowly or fast growing series | Not for alternating series |
| Growth check | Slow growth → +; doubling → ×2 ± c; very fast → squares / cubes | First 5-second scan | Only a hint |
| Split the series | If values zig-zag, separate odd and even positions | Alternating patterns | Needs 7+ terms to confirm |
| Test the rule on all terms | Verify the rule on every given term | Before answering | Skipping this causes most errors |

**C. Three Mandatory Solved Examples**

**Easy**
4, 9, 14, 19, ? (a) 22 (b) 23 (c) 24 (d) 25.
1. Difference is +5 each time.
2. 19 + 5 = **24**. Answer: **(c)**.
- Fastest method: constant difference. Time: **8 s**.
- Common mistake: miscounting the first difference.

**Medium**
2, 6, 12, 20, 30, ? (a) 40 (b) 42 (c) 44 (d) 46.
1. Differences: 4, 6, 8, 10 → next 12.
2. 30 + 12 = **42**. Answer: **(b)**.
- Fastest method: difference ladder. Time: **25 s**. (Also n(n + 1): 6 × 7 = 42.)
- Common mistake: assuming a constant difference of 10.

**Tough**
2, 5, 4, 10, 8, 15, 16, 20, ? (a) 24 (b) 25 (c) 30 (d) 32.
1. Zig-zag growth → split. Odd positions: 2, 4, 8, 16 (×2). Even positions: 5, 10, 15, 20 (+5).
2. The 9th term is the next odd-position term: 16 × 2 = **32**. Answer: **(d)**.
- Fastest method: split into two series. Time: **45 s**.
- Common mistake: continuing the even series (25) because the last term belongs to it.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) 7, 14, 21, 28, ? (a) 32 (b) 35 (c) 36 (d) 42. **Answer (b).** +7.
2. (Easy) A, C, E, G, ? (a) H (b) I (c) J (d) K. **Answer (b).** +2.
3. (Medium) 1, 4, 9, 16, 25, ? (a) 30 (b) 35 (c) 36 (d) 49. **Answer (c).** n².
4. (Medium) 2, 3, 5, 7, 11, 13, ? (a) 15 (b) 17 (c) 19 (d) 21. **Answer (b).** Primes.
5. (Tough) 3, 8, 18, 38, 78, ? (a) 148 (b) 156 (c) 158 (d) 160. **Answer (c).** ×2 + 2: 78 × 2 + 2 = 158.

**E. Exam-Oriented Application**
Series is a standard Reasoning and Quant crossover. I could not verify AAI-specific frequency. Priority: difference ladder and alternating-series split.

**F. Quick Revision**
- Rules: differences → second differences → ×k ± c → squares/cubes → alternating.
- Time-savers: growth check; split the series.
- Reminders: verify the rule on all terms.
- Mistakes: continuing the wrong sub-series; stopping at the first partial pattern.

## 4. Coding-Decoding

**A. Important Formulas and Concepts**

| Type | Method |
|---|---|
| Letter shift | Same shift, alternate shifts, increasing shifts (+1, +2, +3 …) |
| Opposite letters | Position + opposite = 27 |
| Position value | A = 1 … Z = 26; sum or product of values |
| Word / sentence code | Compare statements; the common word has the common code |
| Number / substitution | Build a letter → digit table from the given words |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Write positions | Put numbers under each letter | Any letter code | Takes 10 s extra but prevents slips |
| Common-word elimination | Find the word common to two statements and the code common to both | Sentence codes | Needs at least two overlapping statements |
| Table method | Make a letter ↔ code table while reading | Number substitution | Check every given word against the table |
| Quick checks | First letter shift then last letter | Option elimination | Alternate-shift codes need the full word |

**C. Three Mandatory Solved Examples**

**Easy**
If APPLE is coded as BQQMF, how is MANGO coded? (a) NBOHP (b) NBOGP (c) LZMFN (d) NBPHO.
1. A → B, P → Q, L → M, E → F: each letter +1.
2. M → N, A → B, N → O, G → H, O → P → **NBOHP**. Answer: **(a)**.
- Fastest method: check the shift on the first letter, then confirm. Time: **15 s**.
- Common mistake: shifting by −1.

**Medium**
In a code, "tom dif sak" means "good red apple", "sak ron" means "sweet apple" and "dif hup" means "red rose". What is the code for "good"? (a) dif (b) sak (c) tom (d) ron.
1. "Apple" is common to statements 1 and 2; "sak" is common to the codes → apple = sak.
2. "Red" is common to statements 1 and 3; "dif" is common → red = dif.
3. In statement 1 the remaining word "good" has the remaining code **tom**. Answer: **(c)**.
- Fastest method: common-word elimination. Time: **30 s**.
- Common mistake: assuming codes are in the same order as the words.

**Tough**
If PLANE is coded as QJBLF, how is HOUSE coded? (a) IMVQF (b) IMVSF (c) JMVQF (d) IMUQF.
1. P → Q (+1), L → J (−2), A → B (+1), N → L (−2), E → F (+1): alternate +1, −2.
2. H +1 = I; O −2 = M; U +1 = V; S −2 = Q; E +1 = F → **IMVQF**. Answer: **(a)**.
- Fastest method: write the shifts above the letters first. Time: **50 s**.
- Common mistake: spotting +1 on the first two letters and then applying +1 to every letter.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) If CAT = DBU, then DOG = ? (a) EPH (b) EPG (c) CNF (d) EOH. **Answer (a).** +1 each.
2. (Easy) If A = 1, B = 2, … what is the sum of the letter values of BAD? (a) 6 (b) 7 (c) 8 (d) 9. **Answer (b).** 2 + 1 + 4 = 7.
3. (Medium) If FRIEND = HUMJTK, then CANDLE = ? (a) EDRIRL (b) EDRIRK (c) FDRIRL (d) EDQIRL. **Answer (a).** Shifts +2, +3, +4, +5, +6, +7 applied to C, A, N, D, L, E → E, D, R, I, R, L.
4. (Medium) If ROSE = 6821, CHAIR = 73456 and PREACH = 961473, then SEARCH = ? (a) 214673 (b) 214637 (c) 241673 (d) 214763. **Answer (a).** Table: R = 6, O = 8, S = 2, E = 1, C = 7, H = 3, A = 4, I = 5, P = 9. SEARCH = 2, 1, 4, 6, 7, 3.
5. (Tough) If TABLE = UCEPJ, then CHAIR = ? (a) DJDMW (b) DJDLW (c) DKDMW (d) DJDMV. **Answer (a).** Increasing shifts +1 to +5: C+1 = D, H+2 = J, A+3 = D, I+4 = M, R+5 = W.

**E. Exam-Oriented Application**
Coding-Decoding is a staple of general reasoning sections. I could not verify AAI-specific frequency. Priority: letter shifts (constant, alternate, increasing) and common-word elimination.

**F. Quick Revision**
- Rules: write positions; test constant, alternate, increasing shifts; opposite = 27.
- Time-savers: common-word elimination; letter ↔ code table.
- Reminders: verify the rule on the last letter too.
- Mistakes: assuming a constant shift; wrong direction (+ vs −).

## 5. Blood Relations

**A. Important Formulas and Concepts**

| Term | Meaning |
|---|---|
| Paternal / maternal | Father's side / mother's side |
| Father's or mother's brother | Uncle; their wife = aunt |
| Father's or mother's sister | Aunt; their husband = uncle |
| Children of uncle / aunt | Cousins |
| Brother's or sister's children | Nephew (male) / niece (female) |
| Spouse's brother / sister | Brother-in-law / sister-in-law |
| Grandfather's brother | Grand-uncle (great-uncle) |
| Symbol questions | Each symbol is a relation (e.g. + mother, − brother); read left to right |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Start from the speaker or the "that" person | Anchor the tree on a known person | Statement-type questions | Don't start in the middle of a chain |
| Draw a tree with gender marks | Put M / F; generations in rows; marriage as a horizontal line | Multi-step questions | Gender may be unknown; don't assume |
| Translate phrases | "My father's only son" = me or my brother; "only daughter of my mother" = my sister | Tricky phrases | "Only" matters: it removes alternatives |
| Symbol chains | Expand each symbol into a relation, then chain | Coded-relation questions | Gender of the middle person comes from the symbol |
| Don't assume gender | Write "child" unless stated | Neutral names | If the answer needs gender and the data lacks it, "cannot be determined" |

**C. Three Mandatory Solved Examples**

**Easy**
Pointing to a man, Riya says, "He is the son of my mother's only brother." How is the man related to Riya? (a) Brother (b) Cousin (c) Uncle (d) Nephew.
1. Riya's mother's brother = Riya's maternal uncle.
2. The uncle's son = Riya's cousin.
3. Answer: **(b) Cousin**.
- Fastest method: translate the phrase step by step. Time: **15 s**.
- Common mistake: calling him a brother because of "mother's".

**Medium**
A is B's sister. C is B's mother. D is C's father. How is A related to D? (a) Granddaughter (b) Daughter (c) Grandmother (d) Niece.
1. C is the mother of B, and A is B's sister, so C is also A's mother.
2. D is C's father, so D is A's maternal grandfather.
3. A is a sister, so female → **granddaughter**. Answer: **(a)**.
- Fastest method: draw the three generations. Time: **30 s**.
- Common mistake: saying "daughter" by jumping to C.

**Tough**
In a certain code: A × B means A is the father of B; A − B means A is the brother of B; A ÷ B means A is the sister of B; A + B means A is the mother of B. In P × Q − R ÷ S + T, how is Q related to T? (a) Father (b) Maternal uncle (c) Paternal uncle (d) Brother.
1. P is the father of Q. Q is the brother of R. R is the sister of S. S is the mother of T.
2. Q, R and S are siblings (children of P). So Q is the brother of S.
3. S is T's mother, so Q is T's mother's brother = **maternal uncle**. Answer: **(b)**.
- Fastest method: expand the symbols and group siblings. Time: **50 s**.
- Common mistake: calling Q the "paternal uncle" because P is a father in the chain.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) How is the daughter of my father's brother related to me? (a) Sister (b) Cousin (c) Niece (d) Aunt. **Answer (b).** Uncle's daughter = cousin.
2. (Easy) A is B's brother and B is C's father. How is A related to C? (a) Father (b) Grandfather (c) Uncle (d) Nephew. **Answer (c).** Father's brother = uncle.
3. (Medium) Introducing a woman, a man says, "Her mother is the only daughter of my mother." How is the woman related to the man? (a) Sister (b) Niece (c) Daughter (d) Aunt. **Answer (b).** The only daughter of his mother = his sister; her daughter = niece.
4. (Medium) Pointing to a photograph, a man says, "I have no brother or sister, but that man's father is my father's son." Whose photograph is it? (a) His own (b) His son (c) His father (d) His nephew. **Answer (b).** My father's son (no siblings) = me, so that man's father is me → the man is my son.
5. (Tough) A is the brother of B. C is the father of A. D is the son of B. E is the brother of C. How is E related to D? (a) Uncle (b) Grandfather (c) Grand-uncle (d) Cousin. **Answer (c).** C is the father of both A and B, so C is D's grandfather; E is C's brother → D's grand-uncle.

**E. Exam-Oriented Application**
Blood Relations is a commonly taught general reasoning topic. I could not verify AAI-specific frequency. Priority: phrase translation and symbol chains.

**F. Quick Revision**
- Rules: father's / mother's brother = uncle; their children = cousins; only = no other.
- Time-savers: draw generations; expand symbols.
- Reminders: don't assume gender; start at the speaker.
- Mistakes: confusing paternal / maternal; skipping "only".

## 6. Direction Sense

**A. Important Formulas and Concepts**

| Concept | Rule |
|---|---|
| Directions | N, E, S, W; NE, SE, SW, NW in between |
| Turns | Facing N: right = E, left = W. Facing E: right = S, left = N. Facing S: right = W, left = E. Facing W: right = N, left = S |
| Shortest distance | Net displacement; Pythagoras: √(x² + y²) |
| Common triples | 3-4-5, 5-12-13, 8-15-17, 6-8-10 |
| Shadows | Morning: the sun is in the east, so shadows fall west. Evening: shadows fall east. At noon (sun overhead) shadows are tiny |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Net displacement | Add east − west and north − south separately | Multi-leg walks | Don't add distances in a straight sum |
| Coordinate notebook | Mark (x, y) after each leg | Long routes | Needs care with left / right |
| Triple spotting | Spot 3-4-5, 5-12-13, 8-15-17 | Distance questions | Only for neat numbers |
| Shadow rule | Morning shadow west, evening shadow east | Shadow questions | Assumes the time is stated as morning / evening |
| Facing turn table | Memorise the right / left table above | Turn sequences | Don't confuse your right with the map's right |

**C. Three Mandatory Solved Examples**

**Easy**
A man faces north. He turns right, then left, then left. Which direction is he now facing? (a) North (b) East (c) South (d) West.
1. North → right = East.
2. East → left = North.
3. North → left = **West**. Answer: **(d)**.
- Fastest method: apply the turn table. Time: **15 s**.
- Common mistake: reversing right and left.

**Medium**
A man walks 3 km south, then turns left and walks 4 km. How far and in which direction is he from the starting point? (a) 5 km south-east (b) 7 km south-east (c) 5 km north-east (d) 7 km north-west.
1. Facing south, left = east. Position: 3 km south, 4 km east.
2. Distance = √(3² + 4²) = 5 km.
3. He is south and east of the start → **5 km south-east**. Answer: **(a)**.
- Fastest method: 3-4-5 triple. Time: **25 s**.
- Common mistake: adding 3 + 4 = 7.

**Tough**
A man walks 20 m east, turns left and walks 15 m, then turns left again and walks 12 m. How far and in which direction is he from the starting point? (a) 17 m north-east (b) 17 m north-west (c) 13 m north-east (d) 25 m north-east.
1. Start (0, 0). 20 m east → (20, 0), facing east.
2. Left = north: 15 m → (20, 15), facing north.
3. Left = west: 12 m → (8, 15).
4. Distance = √(8² + 15²) = **17 m** (8-15-17 triple); he is north and east → north-east. Answer: **(a)**.
- Fastest method: coordinates + triple. Time: **45 s**.
- Common mistake: forgetting that after the second left turn he moves west, not east.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) One morning after sunrise, Anil and Sunil stand facing each other. Anil's shadow falls exactly to his right. Which direction is Sunil facing? (a) North (b) East (c) South (d) West. **Answer (a).** Morning shadows fall west. West is Anil's right, so Anil faces south; Sunil faces him, so he faces north.
2. (Easy) Facing east, a girl turns left, then right, then right. Which direction is she facing? (a) North (b) East (c) South (d) West. **Answer (c).** E → left N → right E → right S.
3. (Medium) A walks 6 km north, 8 km east, then 6 km south. How far is he from the start? (a) 6 km (b) 8 km (c) 10 km (d) 14 km. **Answer (b).** The north and south legs cancel; 8 km east remains.
4. (Medium) Priya walks 9 km west, turns right and walks 12 km. How far is she from the start, and in which direction? (a) 15 km north-west (b) 15 km south-west (c) 21 km north-west (d) 13 km north-west. **Answer (a).** West → right = north. (−9, 12): √(81 + 144) = 15 (9-12-15 triple); north-west.
5. (Tough) X walks 4 km south, 7 km west, 8 km north and 4 km east. How far, and in which direction, is he from the start? (a) 5 km north-west (b) 5 km north-east (c) 3 km north-west (d) 7 km north-west. **Answer (a).** (0, −4) → (−7, −4) → (−7, 4) → (−3, 4). Distance √(9 + 16) = 5; he is west and north → north-west.

**E. Exam-Oriented Application**
Direction Sense is a fast, scoring topic in general reasoning. I could not verify AAI-specific frequency. Priority: coordinate notebook and Pythagorean triples.

**F. Quick Revision**
- Rules: turn table; net displacement; √(x² + y²).
- Time-savers: 3-4-5, 5-12-13, 8-15-17; shadow rule.
- Reminders: morning shadow = west.
- Mistakes: adding distances directly; swapping left and right.

## 7. Ranking & Order

**A. Important Formulas and Concepts**

| Concept | Rule |
|---|---|
| Total | Rank from top + rank from bottom − 1 |
| Rank from the other end | Total − rank + 1 |
| Persons between two | Difference of positions − 1 |
| Left / right rows | Position from left + position from right − 1 = total |
| Order comparison | Build one chain with > or < symbols |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Total formula | Top + bottom − 1 | Single-person rank | Needs both ranks of the same person |
| Swap trick | After a swap, one person takes the other's old position | Interchange questions | Use the new position of the same person with the other's old position from the other end |
| Chain building | Write short chains and join them via common names | Comparison puzzles | If two chains don't connect, the order is incomplete |
| Convert to one end | Make every position "from left" first | Row problems | Remember to subtract 1 correctly |
| Between formula | Positions difference − 1 | Counting between | Confirm both are from the same end |

**C. Three Mandatory Solved Examples**

**Easy**
Rahul ranks 12th from the top and 18th from the bottom in a class. How many students are there? (a) 28 (b) 29 (c) 30 (d) 31.
1. Total = 12 + 18 − 1 = **29**. Answer: **(b)**.
- Fastest method: formula. Time: **8 s**.
- Common mistake: forgetting the −1 (30).

**Medium**
In a row, Ravi is 10th from the left and Sam is 15th from the right. When they interchange positions, Ravi becomes 22nd from the left. How many people are in the row? (a) 34 (b) 35 (c) 36 (d) 37.
1. After the swap, Ravi stands where Sam stood. So Sam's old position = 22nd from left and 15th from right.
2. Total = 22 + 15 − 1 = **36**. Answer: **(c)**.
- Fastest method: swap trick. Time: **30 s**. (Ravi's original 10th is a distractor.)
- Common mistake: using 10 and 15 (gives 24).

**Tough**
Six boys A–F are ranked by marks. A scored more than B but less than C. D scored less than E but more than A. F scored less than B. E scored less than C. Who ranks third from the top? (a) A (b) B (c) D (d) E.
1. A < C and A > B → C > A > B.
2. D < E and D > A → E > D > A.
3. F < B. E < C.
4. Join the chains: C > E > D > A > B > F.
5. Third from the top = **D**. Answer: **(c)**.
- Fastest method: chain building. Time: **50 s**.
- Common mistake: placing E above C or leaving D and A unlinked.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) A student is 7th from the top and 24th from the bottom. How many students are in the class? (a) 29 (b) 30 (c) 31 (d) 32. **Answer (b).** 7 + 24 − 1 = 30.
2. (Easy) In a class of 45, Meena's rank from the bottom is 10th. What is her rank from the top? (a) 34 (b) 35 (c) 36 (d) 37. **Answer (c).** 45 − 10 + 1 = 36.
3. (Medium) In a row, A is 11th from the left and B is 14th from the right. A is to the left of B and 8 people are between them. How many people are in the row? (a) 31 (b) 32 (c) 33 (d) 34. **Answer (c).** B is at position 11 + 8 + 1 = 20 from the left; total = 20 + 14 − 1 = 33.
4. (Medium) P is taller than Q. R is taller than P. S is shorter than Q. Who is second tallest? (a) P (b) Q (c) R (d) S. **Answer (a).** R > P > Q > S.
5. (Tough) In a ranking of 40 students, Rita is 13th from the top. Sita is 9 ranks below Rita. Tina is 7th from the bottom. How many students are between Sita and Tina? (a) 10 (b) 11 (c) 12 (d) 13. **Answer (b).** Sita = 22nd from top; Tina = 40 − 7 + 1 = 34th from top; between = 34 − 22 − 1 = 11.

**E. Exam-Oriented Application**
Ranking questions are short formula plays. I could not verify AAI-specific frequency. Priority: total formula, swap trick and chain building.

**F. Quick Revision**
- Rules: top + bottom − 1 = total; between = difference − 1.
- Time-savers: swap trick; chain building.
- Reminders: use the same end before subtracting.
- Mistakes: forgetting −1; using the original position after a swap.

## 8. Syllogism

**A. Important Formulas and Concepts**

| Statement | Meaning | Conversion |
|---|---|---|
| All A are B | A is inside B | Some B are A (only "some") |
| No A is B | Circles do not touch | No B is A |
| Some A are B | Circles overlap | Some B are A |
| Some A are not B | Part of A is outside B | No conversion |

Two-premise results (A–B, then B–C):

| Premises | Definite conclusion |
|---|---|
| All + All | All A are C (and Some C are A) |
| All + No | No A is C |
| Some + All | Some A are C |
| Some + No | Some A are not C |
| No + All | Some C are not A |
| No + Some | Some C are not A |
| All + Some, Some + Some, No + No | No definite conclusion |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Definite vs possible | Accept a conclusion only if it holds in every Venn diagram | All syllogisms | "Possible" does not mean "follows" |
| Result table | Use the combination table above | Two-premise questions | Learn it with Venn diagrams first |
| Conversion first | Convert each premise before combining | Ask "does a link exist between the two end terms?" | "Some A are not B" cannot be converted |
| Test with a counter-diagram | Try to draw a diagram where the conclusion fails | Doubtful conclusions | Takes 15 s but is the safest |
| No outside knowledge | Use only the given statements | All | Real-life facts must be ignored |

I use the common answer format: Only I / Only II / Both / Neither. Some exams add "either-or" options; follow the convention stated in your exam.

**C. Three Mandatory Solved Examples**

**Easy**
Statements: All dogs are animals. All animals are mortal. Conclusions: I. All dogs are mortal. II. Some mortals are dogs.
(a) Only I (b) Only II (c) Both (d) Neither.
1. All + All → All dogs are mortal ✓ (I).
2. Converse of I: Some mortals are dogs ✓ (II).
3. Answer: **(c) Both**.
- Fastest method: table. Time: **15 s**.
- Common mistake: rejecting II because it says "some".

**Medium**
Statements: Some pens are books. All books are tables. Conclusions: I. Some pens are tables. II. All tables are pens.
(a) Only I (b) Only II (c) Both (d) Neither.
1. Some + All → Some pens are tables ✓.
2. "All tables are pens" cannot be drawn: tables may be larger than books.
3. Answer: **(a) Only I**.
- Fastest method: table. Time: **20 s**.
- Common mistake: reversing "All books are tables".

**Tough**
Statements: All cats are dogs. No dog is a rat. Some rats are birds. Conclusions: I. No cat is a rat. II. Some birds are not dogs. III. Some cats are birds.
(a) Only I (b) Only II (c) I and II (d) All three.
1. All cats are dogs and no dog is a rat → No cat is a rat ✓ (I).
2. No dog is a rat → no rat is a dog. Some rats are birds, and those birds are rats, so they are not dogs → Some birds are not dogs ✓ (II).
3. Cats and birds: no premise links them; the diagram can be drawn with no overlap → III does not follow.
4. Answer: **(c) I and II**.
- Fastest method: chain the first two premises, convert the third. Time: **50 s**.
- Common mistake: accepting III because it is "possible".

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) Statements: All roses are flowers. Some flowers are red. Conclusions: I. Some roses are red. II. Some red things are flowers. (a) Only I (b) Only II (c) Both (d) Neither. **Answer (b).** II is the converse of the second premise. I does not follow (roses may be outside the red part).
2. (Easy) Statements: No teacher is a doctor. All doctors are rich. Conclusions: I. Some rich are not teachers. II. No rich is a teacher. (a) Only I (b) Only II (c) Both (d) Neither. **Answer (a).** No + All → Some C are not A (I). II is too strong.
3. (Medium) Statements: Some A are B. Some B are C. Conclusions: I. Some A are C. II. Some C are A. (a) Only I (b) Only II (c) Both (d) Neither. **Answer (d).** Some + Some gives nothing definite.
4. (Medium) Statements: All A are B. No B is C. Conclusions: I. No A is C. II. Some A are C. (a) Only I (b) Only II (c) Both (d) Neither. **Answer (a).** All + No → No A is C; II contradicts it.
5. (Tough) Statements: Some pencils are erasers. All erasers are sharpeners. No sharpener is a ruler. Conclusions: I. Some pencils are sharpeners. II. Some pencils are not rulers. III. No eraser is a ruler. IV. Some sharpeners are pencils. (a) Only I and II (b) Only II and III (c) Only I, III and IV (d) All four. **Answer (d).** Some + All → I; converse → IV; All + No → III; the pencil-erasers are sharpeners and so not rulers → II.

**E. Exam-Oriented Application**
Syllogism is a standard logical-reasoning topic in many government exams. I could not verify AAI-specific frequency. Priority: Venn diagrams, the result table, and the "definite vs possible" check.

**F. Quick Revision**
- Rules: All + All = All; All + No = No; Some + All = Some; Some + No = Some not; No + All = Some not.
- Time-savers: result table; counter-diagram test.
- Reminders: "Some" never gives "All"; ignore real-world facts.
- Mistakes: treating possible as definite; reversing "All".

## 9. Seating Arrangement

**A. Important Formulas and Concepts**

| Concept | Rule |
|---|---|
| Linear row facing north | Your left = the left of the diagram; right = the right of the diagram |
| Linear row facing south | Left and right flip (your left is the diagram's right) |
| Circular, facing the centre | Your **right is anticlockwise**, your **left is clockwise** |
| Circular, facing outwards | Right and left flip |
| Opposite (n people in a circle, n even) | Position + n/2 |
| Between / adjacent / second to … | Count positions step by step |

In this guide, circular seats are numbered 0, 1, 2 … **clockwise**, so for someone facing the centre: right = one number lower, left = one number higher.

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Fix the most definite clue first | Place a person with an absolute position (end seat, "opposite") | Every set | If no clue is absolute, fix one person at 0 in a circle (rotation does not matter) |
| Number the seats | Draw 0 … n − 1 and write names | Circular sets | Slower to draw, far fewer errors |
| Positive clues before negative | "Not adjacent" clues only prune the last choices | Every set | Negative clues can finish the set |
| Left / right check | Say "facing centre: right = anticlockwise" before the first clue | Circular sets | Don't mix facing directions in one set |
| Keep two-case branches short | If a clue gives two cases, test the next clue on both | Ambiguous start | Don't branch more than twice |

**C. Three Mandatory Solved Examples**

*Time estimates: per question when the arrangement is given; for a whole set of 4–5 questions, plan the full-arrangement time stated below.*

**Easy**
Five persons A, B, C, D and E sit in a row facing north. A is at the extreme left. E is at the extreme right. B sits immediately to the right of A. D sits immediately to the left of E. Who sits in the middle? (a) B (b) C (c) D (d) E.
1. Positions 1–5: A at 1, E at 5.
2. B at 2 (immediate right of A); D at 4 (immediate left of E).
3. C takes position 3 → arrangement A B C D E. Answer: **(b) C**.
- Fastest method: place the extremes first. Time: **20 s** for the question (about 45 s for a full set of this size).
- Common mistake: putting B to A's left.

**Medium**
Six persons A–F sit around a circular table facing the centre. A sits opposite D. B sits second to the left of A. C sits immediately to the left of D. E sits immediately to the right of A. Who sits opposite B? (a) C (b) E (c) F (d) A.
1. Number seats 0–5 clockwise. Put A at 0, so D (opposite) is at 3.
2. Facing the centre, left = clockwise. B second to the left of A → seat 2. C immediately to the left of D → seat 4.
3. E immediately to the right of A → anticlockwise → seat 5. The remaining seat 1 is F.
4. Clockwise: A, F, B, D, C, E. Opposite B (seat 2) is seat 5 = **E**. Answer: **(b)**.
- Fastest method: number the seats and place opposite pairs first. Time: **70 s** for the question; about **4 minutes** for a set of 4–5 questions including drawing.
- Common mistake: treating left as anticlockwise.

**Tough**
Eight persons P, Q, R, S, T, U, V and W sit around a circular table facing the centre. P sits second to the right of Q. R sits opposite Q. S sits immediately to the left of R. T sits adjacent to Q but not at Q's immediate right. U sits third to the right of S. V does not sit adjacent to P. Who sits opposite P? (a) T (b) U (c) V (d) W.
1. Put Q at seat 0. Right = anticlockwise: P second to the right → seat 6.
2. R opposite Q → seat 4. S immediately to the left of R → seat 5.
3. Q's immediate right is seat 7, so T (adjacent but not there) is at seat 1.
4. U third to the right of S: 5 − 3 = seat 2.
5. Seats 3 and 7 remain for V and W. Seat 7 is adjacent to P (seat 6), so V takes seat 3 and W seat 7.
6. Clockwise from Q: Q, T, U, V, R, S, P, W. Opposite P (seat 6) is seat 2 = **U**. Answer: **(b)**.
- Fastest method: fix Q at 0 and place the absolute clues (opposite, second right) first; keep the negative clues for the last two seats. Time: **90–120 s** for the question; about **6–8 minutes** for a full set.
- Common mistake: using "not adjacent to P" too early and creating extra cases.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) Five persons P, Q, R, S and T sit in a row facing north. P is at the extreme left, T at the extreme right, S immediately left of T, and Q immediately right of P. Who sits in the middle? (a) Q (b) R (c) S (d) T. **Answer (b).** P Q R S T.
2. (Easy) A, B, C and D sit in a row facing north. A is not at either end. B is at the right end. C sits immediately to the left of A. D does not sit next to B. Who sits at the left end? (a) A (b) B (c) C (d) D. **Answer (d).** A is in seat 2 or 3. C is immediately left of A. If A were in seat 2 then C = 1 and D = 3, next to B, which is not allowed. So A = 3, C = 2, D = 1: D C A B.
3. (Medium) K, L, M, N, O and Q sit in a row facing north. N sits at an extreme end. M sits third to the right of N. L sits immediately left of M. K sits second to the right of L. Q does not sit next to K. Who sits at the right end? (a) K (b) L (c) O (d) Q. **Answer (c).** N must be at the left end (nobody can be third to the right of the right end). M = 4, L = 3, K = 5. Q cannot be next to K, so Q = 2 and O = 6. N Q L M K O.
4. (Medium) Six persons U, V, W, X, Y and Z sit around a circle facing the centre. U sits immediately to the right of V. W sits opposite V. X sits second to the left of U. Y sits opposite X. Who sits opposite U? (a) W (b) X (c) Y (d) Z. **Answer (d).** Put U at 0; V at 1 (U is V's right neighbour). W = 4. X = 0 + 2 = 2. Y = 5. Z = 3, opposite U. Clockwise: U, V, X, Z, W, Y.
5. (Tough) Seven persons A–G sit around a circle facing the centre. B sits second to the right of A. C sits adjacent to A but not at A's immediate left. D sits third to the left of B. E does not sit adjacent to D. F sits immediately to the right of E. G sits adjacent to B. Who sits second to the left of F? (a) B (b) C (c) E (d) G. **Answer (d).** A = 0, B = 5, C = 6 (A's immediate left is seat 1, which is excluded), D = 5 + 3 = 8 mod 7 = 1. E not adjacent to D → E in 3 or 4; F is E's right neighbour (one lower). With E = 3, F = 2 and G (adjacent to B) = 4. Clockwise: A, D, F, E, G, B, C. Second to the left of F (seat 2) is seat 4 = G. (Set time: about 6 minutes.)

**E. Exam-Oriented Application**
Seating Arrangement is a core logical-reasoning topic in many government exams. I could not verify whether AAI JE (Operations) uses it or how long the sets are. Priority: circular facing-centre sets and linear sets with absolute clues.

**F. Quick Revision**
- Rules: facing centre → right = anticlockwise; north-facing row → left is diagram-left.
- Time-savers: fix absolute clues; number seats; negative clues last.
- Reminders: say "left = clockwise" before starting.
- Mistakes: swapping left / right; branching too early.

## 10. Puzzles

**A. Important Formulas and Concepts**

| Puzzle type | Core idea |
|---|---|
| Floor / row | Use ordered positions; "immediately" fixes neighbours |
| Day / date schedule | Days in order; "before / after" give inequalities |
| Comparison | Join short chains with >, < |
| Attribute (grid) | Rows = people, columns = attributes; fill certain facts, cross out impossible ones |
| Truth / lie | Test one person's statement at a time; check consistency |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Grid + crosses | Put ✓ and ✗ in a people × attribute grid | Attribute puzzles | Needs a clean table |
| Direct clues first | Start with the clue that names one person and one fact | Every puzzle | Don't skip negative clues; they finish the grid |
| Elimination by position | A position that can hold only one person becomes certain | Floor and day puzzles | Re-scan after each placement |
| Assume and test | Assume a statement is true; check for contradiction | Truth / lie puzzles | Test all cases |
| Verify at the end | Re-read every clue against the final answer | Always | 15 s that catches mistakes |

**C. Three Mandatory Solved Examples**

*Time estimates: stated per question and, where relevant, for the whole set.*

**Easy**
Five persons P, Q, R, S and T live on five floors (1 = lowest, 5 = top), one per floor. P lives on floor 3. Q lives immediately above P. S lives immediately below P. R lives above Q. Who lives on floor 1? (a) Q (b) R (c) S (d) T.
1. P = 3, Q = 4 (immediately above), S = 2 (immediately below).
2. R lives above Q → R = 5. The remaining floor 1 is T.
3. Answer: **(d) T**.
- Fastest method: place the "immediately" clues first. Time: **25 s** for the question (about 1.5 minutes for a set of 3–4 questions).
- Common mistake: placing R on floor 5 before checking Q's position.

**Medium**
Six friends A–F each visit a doctor on a different day from Monday to Saturday. A visits on Wednesday. B visits two days after A. C visits the day before A. E visits before C. D visits after B. Who visits on Thursday? (a) B (b) D (c) E (d) F.
1. A = Wed. B = Fri (two days after). C = Tue (the day before A).
2. E visits before C → the only earlier day is Monday → E = Mon.
3. D visits after B (Fri) → D = Sat. The remaining Thursday is F.
4. Answer: **(d) F**.
- Fastest method: write Mon–Sat in a row and fill in the exact-day clues first. Time: **40 s** (about 2 minutes for a set).
- Common mistake: reading "two days after A" as Thursday.

**Tough**
Four friends A, B, C and D live in flats numbered 1 to 4 (one each). Each has a different profession (Doctor, Engineer, Pilot, Teacher) and a different pet (Dog, Cat, Parrot, Fish). A is the teacher and lives in flat 2. The pilot lives in flat 1. The doctor lives in flat 4. C owns the dog. The engineer owns the parrot. The fish belongs to the pilot. D lives in a flat adjacent to C's flat. Who owns the cat? (a) A (b) B (c) C (d) D.
1. A = flat 2, teacher. Pilot = flat 1, doctor = flat 4, so the engineer = flat 3.
2. B, C, D occupy flats 1, 3, 4. D is adjacent to C, so D and C take flats 3 and 4 (flats 3 and 4 are adjacent), leaving B in flat 1 = pilot, who owns the fish.
3. The engineer (flat 3) owns the parrot. C owns the dog, so C is not the engineer → C = flat 4, doctor; D = flat 3, engineer, parrot.
4. Remaining pet: cat → A.
5. Answer: **(a) A**.
- Fastest method: build a 4 × 3 grid and use fixed flats to pin professions first. Time: **3–4 minutes** for this single question including the grid (a set of 4–5 questions on one grid would take about 7–8 minutes in total).
- Common mistake: forgetting that "adjacent flats" removes the pair (1, 3) and (1, 4) for C and D.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) W, X, Y and Z live on four floors (1 = lowest). Z lives on floor 1. W lives immediately below X. X lives above Y. Y lives above Z. Who lives on floor 3? (a) W (b) X (c) Y (d) Z. **Answer (a).** Floors 2–4 hold W, X, Y with W immediately below X. If W = 2, X = 3, Y = 4, X would not be above Y. So W = 3, X = 4, Y = 2.
2. (Easy) Q is older than P but younger than R. S is older than R. T is younger than P. Who is second oldest? (a) Q (b) R (c) S (d) T. **Answer (b).** S > R > Q > P > T.
3. (Medium) Five lectures P, Q, R, S and T are held on five days, Monday to Friday, one per day. Q is on Thursday. P is before Q. S is after Q. T is on the day immediately after R. R is not on Monday. Who is on Wednesday? (a) P (b) R (c) S (d) T. **Answer (d).** S = Fri (the only day after Thu). P, R, T share Mon–Wed. R not Mon and T immediately after R → R = Tue, T = Wed, P = Mon.
4. (Medium) A says, "B is lying." B says, "C is lying." C says, "A and B are both lying." Who is telling the truth? (a) Only A (b) Only B (c) Only C (d) A and C. **Answer (b).** If A is truthful, B lies, so C is truthful; then C's claim that A lies is false: contradiction. If C is truthful, A and B lie; then A's "B is lying" would be true: contradiction. If B is truthful, C lies and A lies; C's claim "both lying" is then false, which is consistent. Only B is truthful.
5. (Tough) Four colleagues K, L, M and N each like a different colour (Red, Blue, Green, Yellow) and use a different mode (Bus, Metro, Car, Bike). K likes red and uses neither car nor bike. The person who likes blue uses a bike. N uses a car. L does not like green. M does not use the metro. N does not like green. Who likes green and how does that person travel? (a) K by metro (b) L by bike (c) M by bus (d) N by car. **Answer (c).** K = red, so K uses bus or metro; N = car. The blue lover uses a bike, so is L or M. If M liked blue, L and N would share green and yellow; L is not green and N is not green, so that is impossible. So L = blue, bike. K and M share bus and metro; M is not metro → M = bus, K = metro. N is not green → N = yellow, leaving M = green. (Single-question time: about 3 minutes.)

**E. Exam-Oriented Application**
Puzzles are time-hungry and are usually attempted after the faster topics. I could not verify whether AAI JE (Operations) includes them. Priority: floor / day puzzles first (quick), attribute grids when time allows.

**F. Quick Revision**
- Rules: direct clues first; "immediately" fixes neighbours; verify at the end.
- Time-savers: grid with crosses; chain building for comparisons.
- Reminders: re-scan after every placement.
- Mistakes: misreading "before / after"; ignoring negative clues.

## 11. Data Sufficiency

**Answer format used in this guide** (exam wording varies, so read the options carefully):
(a) Statement I alone is sufficient; II alone is not. (b) Statement II alone is sufficient; I alone is not. (c) Either statement alone is sufficient. (d) Both together are needed. (e) Even both together are not sufficient.

**A. Important Formulas and Concepts**

| Concept | Rule |
|---|---|
| Sufficient means | The statement gives one definite answer (a definite "Yes" or a definite "No" also counts) |
| Reasoning variety | Ranking, direction, blood relation, seating, coding, comparison |
| Check order | Test I alone, II alone, then both |
| Consistency | If two statements both work alone, they must not contradict each other |
| No assumptions | Use only the given facts and standard rules |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Alone first | Forget the other statement while testing one | Always | Prevents mixing information |
| Sketch the minimal picture | Draw only the people or points involved | Ranking, direction, relation | Don't draw more than the statements give |
| Look for a missing link | A missing link between the question's two items means "not sufficient" | Chain-type questions | Check both statements for the link |
| Two-case test | Show two valid pictures that give different answers → insufficient | Seating, direction | Be sure both pictures obey all statements |
| Use totals for ranks | Top + bottom − 1 gives the class size | Ranking DS | Check both statements are about the same group |

**C. Three Mandatory Solved Examples**

**Easy**
In a class of 30, what is Neha's rank from the top? I. Neha's rank from the bottom is 10. II. Neha is 4 ranks above Meena, who ranks 25th from the top.
1. I alone: rank from top = 30 − 10 + 1 = 21 → sufficient.
2. II alone: Meena is 25th; Neha is 4 ranks above → 21st → sufficient.
3. Both give 21 (consistent). Answer: **(c) Either alone**.
- Fastest method: compute each statement separately. Time: **30 s**.
- Common mistake: using 30 − 10 = 20 (forgetting + 1).

**Medium**
Who is the oldest among A, B and C? I. A is older than B. II. C is older than both A and B.
1. I alone: A > B, but C is unknown → not sufficient.
2. II alone: C is older than both → C is oldest → sufficient.
3. Answer: **(b) II alone**.
- Fastest method: look for the statement that mentions all the people. Time: **20 s**.
- Common mistake: combining the statements when II already settles it.

**Tough**
Six persons A–F sit around a circular table facing the centre. Who sits opposite A? I. B sits immediately to the right of A. II. C sits second to the left of B.
1. Number seats clockwise; A = 0. Facing the centre, right = anticlockwise, so B = 5 (statement I).
2. II: second to the left of B (left = clockwise) → seat 1 = C.
3. Together: A = 0, B = 5, C = 1. The seat opposite A is seat 3, which could hold D, E or F.
4. Answer: **(e) Not sufficient even together**.
- Fastest method: place both statements on a 6-seat circle and look at the opposite seat. Time: **60 s**.
- Common mistake: assuming the unseen seat must be D (alphabetical order).

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) Is Ravi taller than Amit? I. Amit is taller than Kiran. II. Ravi is shorter than Kiran. **Answer (d).** Alone, neither links Ravi with Amit. Together: Amit > Kiran > Ravi, so the answer is a definite "No".
2. (Easy) What is Kiran's rank from the bottom in a class of 40? I. Kiran is 15th from the top. II. Kiran is 10 ranks above Mohan. **Answer (a).** I gives 40 − 15 + 1 = 26. II does not fix Kiran's position.
3. (Medium) How many students are in the class? I. Rohit is 12th from the top and 15th from the bottom. II. Sneha is 7th from the top and 20th from the bottom. **Answer (c).** I: 12 + 15 − 1 = 26. II: 7 + 20 − 1 = 26. Either alone suffices (and they agree).
4. (Medium) In a code language, what is the code for "sky"? I. "sea breeze" is coded "lo pu". II. "blue sky" is coded "ma ri" and "blue sea" is coded "ma lo". **Answer (b).** II: "blue" is common, so blue = ma, so sky = ri. I alone says nothing about sky.
5. (Tough) Five persons P, Q, R, S and T sit in a row facing north. Who sits in the middle? I. P sits at the left end and Q sits immediately right of P. II. T sits at the right end. **Answer (e).** Together: P Q _ _ T, so the middle seat could be R or S. Not determined.

**E. Exam-Oriented Application**
Data Sufficiency in reasoning is logic-first, calculation-light. I could not verify whether AAI JE (Operations) asks it; general competitive exams do use it. Priority: ranking and direction DS, which are the quickest.

**F. Quick Revision**
- Rules: a definite answer (even a definite "No") is sufficient.
- Time-savers: test alone first; draw the minimum picture.
- Reminders: consistency check when both work alone.
- Mistakes: combining before testing alone; assuming extra facts.

## 12. Statement & Conclusion

**Answer formats used here:** conclusions and assumptions: Only I / Only II / Both / Neither (or the lettered options shown). Exams differ in some conventions (especially for "strong / weak argument" and "course of action"), so treat the keys below as the standard textbook convention and follow your exam's instructions.

**A. Important Formulas and Concepts**

| Question type | What to check |
|---|---|
| Conclusion | Does it follow definitely from the statement alone? |
| Assumption | Is it implicit, so that the statement would make no sense without it? |
| Course of action | Is it practical, constructive and directly related to the problem? |
| Argument | Is it strong (relevant, specific, important) or weak (vague, extreme, personal)? |
| Words to watch | "All, only, never, always, every" are extreme; "some, may, can" are safe |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Statement-only rule | Ignore real-world knowledge | Conclusions | Facts given in the statement do count |
| Extreme-word filter | Reject options with "all / never / only" unless the statement says so | Conclusions and assumptions | If the statement itself is extreme ("Only those who…"), the extreme conclusion may follow |
| "Remove it and see" | Delete the assumption; if the statement collapses, it is implicit | Assumptions | Mildly subjective |
| Fix the problem | Choose the action that solves the stated problem without extreme side-effects | Course of action | Keys vary by exam |
| Specific beats vague | A specific, relevant reason is a strong argument | Arguments | Check relevance, not tone |

**C. Three Mandatory Solved Examples**

**Easy**
Statement: Some airports in the country have two runways. Conclusions: I. All airports in the country have two runways. II. At least one airport in the country has two runways. (a) Only I (b) Only II (c) Both (d) Neither.
1. "Some … have" means at least one, so II follows.
2. "All" is not supported, so I does not follow.
3. Answer: **(b) Only II**.
- Fastest method: extreme-word filter. Time: **12 s**.
- Common mistake: reading "some" as "most".

**Medium**
Statement: "Passengers are advised to reach the airport two hours before departure." Assumptions: I. Check-in and security formalities take time. II. All passengers will reach on time. (a) Only I (b) Only II (c) Both (d) Neither.
1. Remove I: the advice has no reason, so I is implicit.
2. II is an extreme claim and is not needed for the advice to make sense.
3. Answer: **(a) Only I**.
- Fastest method: "remove it and see". Time: **25 s**.
- Common mistake: accepting II because it "sounds like the goal".

**Tough**
Statement: "Only those who submitted both forms A and B were allowed to enter the exam hall. Rohit was allowed to enter." Conclusions: I. Rohit submitted form A. II. Rohit submitted form B. III. Rohit submitted only form A. (a) Only I (b) Only II (c) I and II (d) All three.
1. "Only those who submitted both A and B were allowed" → allowed ⇒ submitted both.
2. Rohit was allowed, so he submitted A (I) and B (II).
3. III says he submitted only A, which contradicts "both".
4. Answer: **(c) I and II**.
- Fastest method: turn "only those who…" into "allowed ⇒ both". Time: **35 s**.
- Common mistake: rejecting I and II as "too extreme"; here the statement itself is the extreme one.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) Statement: Raman is taller than Shyam. Conclusions: I. Shyam is shorter than Raman. II. Shyam is the shortest boy in the class. (a) Only I (b) Only II (c) Both (d) Neither. **Answer (a).** I restates the statement; II adds new information.
2. (Easy) Statement: Every student of the batch passed the mock test. Conclusions: I. No student of the batch failed. II. Some students scored above 90. (a) Only I (b) Only II (c) Both (d) Neither. **Answer (a).** I follows; II is not given.
3. (Medium) Statement: "Use biometric check-in to avoid long queues." Assumptions: I. Biometric check-in is faster than manual check-in. II. Passengers dislike biometric systems. (a) Only I (b) Only II (c) Both (d) Neither. **Answer (a).** The advice makes sense only if biometric check-in is faster. II is unrelated.
4. (Medium) Should night landings be banned at all airports? Arguments: I. Yes, they are risky in all conditions. II. No, modern navigation aids make them safe and allow runways to be used more efficiently. (a) Only I is strong (b) Only II is strong (c) Both are strong (d) Neither is strong. **Answer (b).** I is an extreme claim ("all conditions"); II gives a specific, relevant reason. (Textbook convention; exam keys may differ.)
5. (Tough) Statement: Several flights from the city airport were delayed because of dense fog for the third consecutive day. Courses of action: I. The airport authority should install better low-visibility landing aids. II. All flights in winter should be permanently cancelled. III. Airlines should inform passengers about delays in advance. (a) Only I (b) Only II (c) I and III (d) All three. **Answer (c).** I and III are practical and relevant; II is an extreme overreaction.

**E. Exam-Oriented Application**
These questions test careful reading more than knowledge. I could not verify whether AAI JE (Operations) asks them. Priority: the extreme-word filter and the "remove it and see" test.

**F. Quick Revision**
- Rules: statement-only; implicit assumption = statement collapses without it.
- Time-savers: extreme-word filter; turn "only those who…" into an if-then.
- Reminders: "some" means at least one.
- Mistakes: using outside knowledge; accepting extreme actions.

## 13. Mirror & Water Images

**A. Important Formulas and Concepts**

| Concept | Rule |
|---|---|
| Mirror image | Left-right swap (vertical mirror). For a word, the order of letters reverses and each letter is laterally flipped |
| Water image | Top-bottom swap (horizontal mirror, as in water below the object). The letter order stays; each letter is flipped upside-down |
| Letters unchanged in a mirror (laterally symmetric) | A, H, I, M, O, T, U, V, W, X, Y |
| Letters unchanged in water (vertically symmetric) | B, C, D, E, H, I, K, O, X |
| Digits (usual convention) | Mirror-symmetric: 0, 1, 8. Water-symmetric: 0, 3, 8 (conventions vary) |
| Clock in a mirror | Actual time = 11:60 − time seen (add 12 hours if the result is negative) |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Symmetric-letter shortcut | If every letter is symmetric about the mirror line, the image is the word with reversed (mirror) or unchanged (water) order | Word questions | Only for fully symmetric words |
| Reverse-order check | A mirror image reverses the order of letters; a water image does not | Word and number sequences | Remember that each letter also flips |
| 11:60 rule | Subtract the clock time from 11:60 | Mirror clock time | Water-image clock reading is not an exact rule; avoid memorising a formula for it |
| Hand-position check | Hour-hand and minute-hand angle relationships are preserved in a mirror | Verifying a clock answer | Needs care with angles |
| Eliminate by one letter | Test only the most asymmetric letter (e.g. F, R, G) | Option elimination | The other letters may still differ |

**C. Three Mandatory Solved Examples**

**Easy**
Which letter's mirror image (in a vertical mirror) looks identical to the letter? (a) F (b) A (c) G (d) R.
1. A is laterally symmetric (left half = right half).
2. F, G and R change when flipped left-right.
3. Answer: **(b) A**.
- Fastest method: use the laterally symmetric list. Time: **8 s**.
- Common mistake: confusing mirror symmetry with water symmetry (B, C, D, E look the same in water but not in a mirror).

**Medium**
A clock shows 4:20. What time does its mirror image show? (a) 7:30 (b) 7:40 (c) 8:20 (d) 8:40.
1. Mirror time = 11:60 − 4:20 = 7:40.
2. Check: hour hand at 4:20 is 130°; in the mirror it is 360° − 130° = 230°, which is 7:40's hour-hand position.
3. Answer: **(b) 7:40**.
- Fastest method: 11:60 − time. Time: **15 s**.
- Common mistake: subtracting from 12:00 and forgetting that the 11:60 form (or an extra borrow of 60 minutes) is needed for times with minutes.

**Tough**
In a mirror, a clock appears to show 2:50. What is the actual time, and what is the smaller angle between the hands at the actual time? (a) 9:10, 145° (b) 9:10, 155° (c) 8:50, 145° (d) 9:50, 155°.
1. Actual time = 11:60 − 2:50 = 9:10.
2. Angle = |30H − 5.5M| = |30 × 9 − 5.5 × 10| = |270 − 55| = 215°.
3. The smaller angle = 360° − 215° = 145°.
4. Answer: **(a)**.
- Fastest method: 11:60 rule, then |30H − 5.5M|. Time: **55 s**.
- Common mistake: stopping at 215° and not taking the smaller angle.

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) Which word looks the same in its water image? (a) BOX (b) MAT (c) TOP (d) PAT. **Answer (a).** B, O and X are vertically symmetric.
2. (Easy) What is the mirror image of the word TOM (vertical mirror on the right)? (a) MOT (b) TOM (c) OTM (d) MTO. **Answer (a).** T, O and M are laterally symmetric, so only the order reverses.
3. (Medium) A clock shows 7:15. What is its mirror image time? (a) 4:15 (b) 4:45 (c) 5:15 (d) 5:45. **Answer (b).** 11:60 − 7:15 = 4:45.
4. (Medium) In a mirror a clock appears to show 10:40. What is the actual time? (a) 1:20 (b) 1:40 (c) 2:20 (d) 12:20. **Answer (a).** 11:60 − 10:40 = 1:20.
5. (Tough) Which word looks the same as itself in its mirror image? (a) ANNA (b) MAT (c) TIP (d) WOW. **Answer (d).** W, O and W are laterally symmetric and the word reads the same reversed. ANNA fails because N is not laterally symmetric; MAT becomes TAM; TIP contains P.

**E. Exam-Oriented Application**
Mirror and water images are quick, rule-based questions when the letters are symmetric. I could not verify whether AAI JE (Operations) asks them. Priority: the letter lists and the 11:60 rule. Picture-based versions need practice from image mocks.

**F. Quick Revision**
- Rules: mirror = left-right swap; water = top-bottom swap; clock mirror = 11:60 − time.
- Time-savers: symmetric-letter lists; test the most asymmetric letter.
- Reminders: mirror reverses word order; water does not.
- Mistakes: mixing the two symmetry lists; forgetting the smaller angle.

## 14. Non-Verbal Reasoning

**Scope note:** this topic is picture-based in the real exam. Here I cover question types that can be shown accurately in text: rotation series, counting figures, cubes and paper folding. Practise figure series, embedded figures and dice-with-pictures from image-based mocks.

**A. Important Formulas and Concepts**

| Concept | Rule |
|---|---|
| Figure series | Look for rotation (45° / 90° steps), shading change, element added or removed, alternating patterns |
| Squares in an n × n grid | n(n + 1)(2n + 1) / 6 (e.g. 3 × 3: 9 + 4 + 1 = 14) |
| Rectangles (including squares) in an n × n grid | [n(n + 1) / 2]² (3 × 3: 36) |
| Triangles with one vertex at A and the opposite side holding k points | Choose 2 of the k points: C(k, 2) |
| Painted cube cut into n³ small cubes | 3 faces: 8; 2 faces: 12(n − 2); 1 face: 6(n − 2)²; no face: (n − 2)³ |
| Paper folded in half k times, hole punched through all layers away from fold lines | 2^k holes |
| Dice | Opposite faces never touch; faces sharing a corner are adjacent |

**B. Best Tricks, Tips and Shortcuts**

| Trick | How it works | When to use | Limitation |
|---|---|---|---|
| Track one element | Follow one symbol through the series | Figure series | Move to the next symbol if two things change at once |
| Rotation counting | Count the turn per step, then extend | Rotation series | Check the direction (clockwise / anticlockwise) |
| Counting formulas | Use the grid, triangle and cube formulas | Counting questions | Formulas assume a clean grid with no extra lines |
| Fold-and-count | Layers double with each fold | Paper folding | If the hole is on a fold line, there are fewer holes |
| Opposite-face rule | Faces that never touch are opposite | Dice | Needs two views |

**C. Three Mandatory Solved Examples**

**Easy**
An arrow rotates 90° clockwise at each step: ↑, →, ↓, ←, ? What comes next? (a) ↑ (b) ↓ (c) → (d) ←.
1. Up → right → down → left: each step is 90° clockwise.
2. The next step from left is up.
3. Answer: **(a) ↑**.
- Fastest method: track the arrow direction. Time: **10 s**.
- Common mistake: reading it as anticlockwise.

**Medium**
How many squares of all sizes are there in a 3 × 3 grid of small squares? (a) 9 (b) 13 (c) 14 (d) 16.
1. 1 × 1 squares: 9. 2 × 2 squares: 4. 3 × 3 squares: 1.
2. Total = 9 + 4 + 1 = **14**. Answer: **(c)**.
- Fastest method: formula n(n + 1)(2n + 1)/6 = 3 × 4 × 7/6 = 14. Time: **15 s**.
- Common mistake: counting only the 9 small squares.

**Tough**
In triangle ABC, three lines are drawn from vertex A to points D, E and F on side BC (so BC holds the points B, D, E, F, C in order). How many triangles are there in the figure? (a) 6 (b) 8 (c) 10 (d) 12.
1. Every triangle has A as one vertex and two of the five base points as the other two.
2. Number of triangles = C(5, 2) = 10.
3. Answer: **(c) 10**.
- Fastest method: choose 2 of the 5 base points. Time: **30 s**.
- Common mistake: counting only the 4 small triangles and the big one (5).

**D. Additional Practice Questions (all ORIGINAL)**

1. (Easy) How many squares of all sizes are in a 2 × 2 grid? (a) 4 (b) 5 (c) 6 (d) 8. **Answer (b).** 4 small + 1 large.
2. (Easy) A 3 × 3 × 3 cube is painted on all faces and cut into 27 small cubes. How many have no face painted? (a) 0 (b) 1 (c) 2 (d) 6. **Answer (b).** (3 − 2)³ = 1.
3. (Medium) How many rectangles (including squares) are in a 3 × 3 grid? (a) 18 (b) 24 (c) 36 (d) 48. **Answer (c).** [3 × 4 / 2]² = 6² = 36.
4. (Medium) A 5 × 5 × 5 cube is painted on all faces and cut into 125 unit cubes. How many have exactly one face painted? (a) 36 (b) 54 (c) 72 (d) 96. **Answer (b).** 6(5 − 2)² = 54.
5. (Tough) A square paper is folded in half three times and a hole is punched through all layers, away from any fold line. How many holes appear when it is unfolded? (a) 3 (b) 6 (c) 8 (d) 9. **Answer (c).** 2³ = 8 layers, so 8 holes.

**E. Exam-Oriented Application**
The official syllabus lists "Reasoning (verbal and non-verbal)", so non-verbal items are expected in Part A, but I could not verify the number of questions or the question types. Priority: counting formulas, cube-painting formulas, and rotation series.

**F. Quick Revision**
- Rules: squares n(n + 1)(2n + 1)/6; painted cube 8 / 12(n − 2) / 6(n − 2)² / (n − 2)³; folds double layers.
- Time-savers: track one element; choose-2 counting for triangles.
- Reminders: opposite dice faces never touch.
- Mistakes: counting only small figures; wrong rotation direction.
